
# Hangman Game - Python

## About the Project
A simple Hangman Game developed using Python as part of the CodeAlpha Python Programming Internship.

## Features
- Random word selection
- Interactive letter guessing
- Maximum of 6 incorrect guesses
- Win and lose messages
- New game option

## Technologies Used
- Python 3
- Tkinter (if using the GUI version)
- Random module

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal and run:

   python hangman.py

## Concepts Used
- Variables
- Lists and strings
- Random module
- Loops
- If-else statements
- Functions
